Ship Loop

flowchart

how an ai agent takes a task to local commits, checked phase by phase.

Claude Code runs this loop to take a task from plan to local commits. A person approves the plan once. For each phase, the agent writes a failing test first and then the code. A second agent that did not write the code reruns the phase's checks. A phase fails when a check fails or when the diff touches a file the plan did not list. The agent gets one retry, then hands both reports to the person. Debt the agent finds goes in a log. The agent leaves that code alone. A killed session resumes from the last checked phase in the plan file. The person pushes the commits.
